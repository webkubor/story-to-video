# 视频热门配乐 (BGM Matcher)

> 🎵 给视频自动推荐当下最火的背景音乐。
> 网易云实时热歌榜 + 热度评分 + 情绪匹配。537 首随取随用，零门槛。

## 这个 Skill 能做什么

做视频最头疼的是找 BGM。输入你的视频文案，立刻返回最匹配的热门歌曲推荐，按热度排序。

## 触发条件

用户说「配乐」「BGM」「背景音乐」「加音乐」「配乐推荐」「视频音乐」等关键词。

## 输入

- **文案/描述**（必须）：视频内容描述，如"治愈温馨的猫咪日常"、"古风旅拍汉服"

## 输出

热门歌曲推荐列表，包含歌名、热度分、情绪标签。

## 用法

```bash
python hot.py fetch               # 拉取最新热歌榜（12h缓存）
python hot.py match "治愈猫咪"      # 推荐配乐
python hot.py weekly              # 每周强制刷新
python hot.py list                # 曲库统计
```

## 热度评分

- 热歌榜 TOP1 → 148.5 分（权重×1.5）
- 抖音榜 TOP1 → 128.7 分（权重×1.3）
- 排名越前分数越高，只推荐真正火的歌
