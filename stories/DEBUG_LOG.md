# 故事视频制作调试日志

## 2026-07-30：小兔子的星星

### 异常记录

| 问题 | 根因 | 修复 |
|------|------|------|
| 字幕重叠 | Remotion 默认每场字幕独立但交接处无 fade | 改用 ffmpeg drawtext + enable='between(t,start,end)' 精确控制 |
| 旁白交叉 | API 按段返回，连续播放无间隔 | 每段后插入 0.5s 静音间隙（ffmpeg adelay） |
| 参考图不可用 | base64 传图超负载 | 改为 CDN URL 直传 |
| 出图失败空返回 | Studio generate 接口超时 | 重试机制 + fallback 手动补图 |

### 经验总结

1. 管线分层：画面 / 字幕 / 旁白 / BGM 四层独立控制
2. 时间轴同步：以旁白为基准，字幕跟随，画面铺底
3. 预留缓冲：每幕过渡至少 0.3s 画面缓冲 + 0.5s 音频静音
