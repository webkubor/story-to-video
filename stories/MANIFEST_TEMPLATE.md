# 出图记录规范

每次生成图片必须记录：

1. **故事名称** - 项目+故事名
2. **场景编号** - 对应故事的第几幕
3. **提示词** - 生成时用的完整 prompt
4. **出图方式** - cs image gen / Studio API / 其他
5. **图片URL** - CDN链接或本地路径
6. **生成时间** - 精确到分钟
7. **是否可用** - 打标 待筛选/可用/废弃

## 目录结构
```
stories/故事名/
├── story.txt          # 故事原文
├── MANIFEST.md        # 出图记录表
├── 01.png             # 场景图片
├── 02.png
└── ...
```

## 铁律
- 每次出图前先查 MANIFEST.md，有可复用的不重复生成
- 废弃的图标注原因，不直接删除（可回溯）
